# Kontrakty

* [Kontrakt HTTP](http-api.md) - Semantyka endpointów /api/products (lista, tworzenie, odczyt, zmiana ceny) i /health: statusy, nagłówki i zasady, których nie widać w schemacie OpenAPI.
* [ProductPriceChanged.v1](product-price-changed-v1.md) - Zdarzenie zmiany ceny w topicu product-price-changed: pola, klucz, nagłówki, gwarancje dostarczenia i wersjonowanie.
* [Schemat bazy](database-schema.md) - Tabele produktów, historii cen, walut i danych technicznych (outbox, inbox, klucze idempotencji): przeznaczenie i indeksy.
